# Agent Guidelines & Skills

## Active Guidelines

This repository follows the **Karpathy Guidelines** for LLM-assisted development:
- **Location:** [skills/karpathy-guidelines/SKILL.md](skills/karpathy-guidelines/SKILL.md)
- **Core Pillars:**
  1. **Think Before Coding:** Make assumptions explicit, surface tradeoffs, never assume silently.
  2. **Simplicity First:** Minimal necessary code, no speculative features or redundant abstractions.
  3. **Surgical Changes:** Modify only what is strictly necessary, clean up orphan references.
  4. **Goal-Driven Execution:** Define measurable success criteria and verify with tests/builds.
